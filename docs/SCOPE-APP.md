# APP 端功能边界（定稿 v1.2）

> v1.0 2026-10-19 首版；v1.1 检测线整体移出；**v1.2 取样改归生产班组、留样入库与借还移 PC、质检不装 APP**（见文末变更记录）。
> 依据：对后端全部 **51 个权限点**逐项分类 + 用户裁决。
> 本文件是 APP 的**功能白名单**：不在此列的权限点，APP 不提供任何入口。

## 一、判据（三条全中才进 APP）

1. **地点**：动作发生在车间 / 磅房 / 装车区 / 现场取样点。
2. **时效**：等不起——车在等、料在等、人在等。
3. **设备**：当时手边没有电脑。

审批类**默认不进**；主数据**一律不进**；**实验室里发生的动作一律不进**（那里有电脑）。

## 五、被砍掉的动作，现场怎么走

| 现场会遇到 | APP 现在怎么表现 | 人该怎么办 |
|---|---|---|
| 车到了但**没预报** | 到货确认页拦截：「该车牌今日无预报」+ 列出该车牌最近 3 条预报 + **一键拨号**给综合运营部 | 电话报车号，PC 补预报，APP 下拉刷新后重试 |
| **新车牌**不在档案 | 同上拦截：「车辆档案不存在」+ 一键拨号 | PC 建档后再收 |
| 取完样**交给质检** | APP 只记录取样（`sampled_by`＝生产班组），**不做交接确认** | 留样袋随物流送到化验室；有争议看取样人 |
| 想把样品**放进留样柜** | APP 无入口 | 化验室 PC 登记柜位与期限 |
| 想知道**这个样测出来多少** | 走 S13 追溯看批次档案的检测结论（只读） | 结论在 PC 出 |
| 现场**想拍照留证**（袋破损、异物） | 无上传入口 | 拍完回实验室随附件传 |
| 投料投错了且**已过本班次** | 更正入口置灰，注明「请到 PC 端更正」 | 电话告知生产主管，PC 改 |
| 需要**紧急放行**（车等卸） | 无入口；「我的 → 帮助」写明流程 + 一键拨号 | 电话主管 → PC 审批 → APP 状态自动变为可收货 |

## 六、三条设计铁律

1. **无入口即无入口。** 页面里不出现任何 PC 专属动作的按钮——灰掉也不行。
2. **越权一律给话术，不给白屏。** 403 时展示「你的角色无此权限，请联系综合运营部」，不显示技术错误码。
3. **拦截必须给下一步。** 原因 + 谁负责 + 怎么联系，缺一不可。

## 八、验收口径（可机检）

- APP 源码中出现以下任一 ⇒ **判失败**：`notice.create` / `md.*` / `void` / `destroy` / `concession` / `urgent` / `conclusion` / `rework` / `export` / `insp.*` / **`retain.in`** / **`retain.lend`**。
- 上述 16 屏之外新增页面 ⇒ 先改本文件再动代码。
- 每页必须有无权限、拦截、断网三态设计稿，缺一态不许进开发。
