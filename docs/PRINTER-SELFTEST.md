# KM-118BT 自测指引（10 分钟，决定 APP 打印主通道）

> 目的：在 APP 开发出来**之前**，用一台 Windows 电脑 + USB 线把两个悬而未决的事实测掉：
> ① 这台机的**实际可打印宽度**到底是不是 102mm（决定 100×100 标签能不能打）；
> ② 它吃 **TSPL** 还是 **ESC/POS** 指令（决定 APP 蓝牙直发的协议）。
> 测完把第五节的表填好、拍两张照片发回来即可。

## 一、需要的东西

| 物品 | 说明 |
|---|---|
| 快麦 KM-118BT 一台 | 装好 100mm 宽热敏标签纸（**纸宽必须 ≥102mm**，别拿 80mm 纸测） |
| Windows 电脑 + USB 线 | 随机附带 |
| 快麦 Windows 驱动 | 官网/驱动盘安装；另需再装一台「**Generic / Text Only**」打印机（见测法 B） |
| 本目录三个文件 | `ruler-100mm.png` · `probe_tspl.txt` · `probe_escpos.bin` |

## 二、测法 A · 实际可打印宽度（决定标签尺寸）

1. 安装快麦驱动后，右键 `ruler-100mm.png` → 打印。
2. **打印对话框里必须选「实际大小 / 100%」，禁止「适合页面 / 适应边距」**——缩放会让结果失真。
3. 打印完成后看标尺：**数字 100 的刻度和最外圈边框是否完整**。

| 结果 | 结论 | 动作 |
|---|---|---|
| 100 刻度与右边框完整（缺 ≤1mm） | 实际可打宽度 ≥100mm | 100×100 标签可行，进入测法 B |
| 100 刻度缺 2mm 以上 | 实际可打宽度 <100mm | **100×100 放不下**：拍照片回传，我们改 80×100 或换机 |
| 整页缩成一小张 | 打印时被缩放了 | 重打，确认选了「实际大小」 |

## 三、测法 B · 指令集探测（决定 APP 蓝牙直发协议）

原理：给同一台 USB 打印机装一台「**Generic / Text Only**」系统打印机（Windows 自带，无需厂商驱动），它会把文件**原样**发给打印机——这是发原始指令的经典做法。

1. 控制面板 → 添加打印机 → 「我所需的打印机未列出」→ 按其他选项添加 → 创建新端口选 USB 虚拟端口（与快麦驱动相同的 USB001）→ 厂商选「Generic」→ 型号「Generic / Text Only」，命名如 `KM-RAW`。
2. 共享该打印机（右键 → 打印机属性 → 共享，共享名如 `KMRAW`）。
3. 管理员命令行执行（两条分开打）：

```bat
copy /b "%USERPROFILE%\path\to\probe_tspl.txt"   \\%COMPUTERNAME%\KMRAW
copy /b "%USERPROFILE%\path\to\probe_escpos.bin" \\%COMPUTERNAME%\KMRAW
```

（`path\to` 换成实际路径；一次发一条，等出纸再发下一条。）

| 结果 | 结论 |
|---|---|
| 发 `probe_tspl.txt` 后出纸，印着 **JX TSPL OK** 和一条横线 | **TSPL 可用** ⇒ APP 主通道定为 TSPL `BITMAP` |
| 发 `probe_escpos.bin` 后出纸，印着 **JX ESC/POS OK** | ESC/POS 可用 ⇒ 备通道 |
| 两条都出纸 | 更好：两条都记为可用，APP 仍按「TSPL 优先」 |
| 两条都不出纸（或只出空白/乱码） | 直发不可行 ⇒ 一期走「系统打印」兜底，另提后端版式页需求 |

> 蓝牙通道的指令集与 USB 通常一致（同一固件）；若要连测蓝牙，把电脑蓝牙与打印机配对出 SPP 串口后用串口工具发同样文件即可，非必需。

## 四、测法 C · 蓝牙配对预检（可选，2 分钟）

手机蓝牙搜索「KM-118BT」能否发现并配对。能配对 ⇒ APP 蓝牙直发可行性 +1；搜不到 ⇒ 记录（部分面单机蓝牙只对专用 APP 可见，那系统打印/USB 就成了唯一通道，须尽早知道）。

## 六、常见坑

- **纸宽 ≠ 可打宽度**：装 100mm 纸，机器最多打到 102mm 里的 100mm，也可能被限到 80mm——所以必须实测，别信商品页参数。
- 测宽度那一张，**标签纸的间隙/黑标设置**若不对会走纸不准：出纸歪斜时在驱动里把「纸张类型」改为「有间隙标签」再试。
- `copy /b` 必须**管理员**命令行；共享名大小写不敏感。
- 若 Generic/Text Only 添加向导里找不到 USB 端口：先装快麦驱动（它建端口），再添加 Generic 时选同一个端口。
